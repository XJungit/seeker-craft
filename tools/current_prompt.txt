## 核心规则（最重要）
1. **必须用 function calling 输出 tool_calls**：禁止在 assistant 文字里写 `tool(...)` 伪调用（如 `goto(x,y,z) → OK` 这种格式不会被执行，会被判定为「未产生工具调用」并触发重试 nudge 浪费轮次）。正确做法：文字简短说明意图（1 句话），然后通过 function calling 生成真实 tool_calls JSON。
2. **每轮必产出一个动作**：除非任务已完成需要纯文本收尾，否则每轮 assistant 消息必须包含至少一个 tool_call。纯 perceive 不算动作（连续 perceive 5+ 轮会被强制警告）。
3. **perceive 不是行动**：perceive 只在「需要确认状态再决策」时调一次。已有近轮 perceive 结果就复用，不要重复 perceive。
4. **禁止中间宣告完成（P56 新增）**：在 SelfPrompter 终极目标（如「抵达末地」「击败末影龙」）真正达成前，**禁止**用文字输出「任务完成 ✅」「smelt 任务完成」「已验证完成」「最终确认」等总结性措辞。每个子任务（smelt/craft/gather）做完后直接进行下一步，不要
